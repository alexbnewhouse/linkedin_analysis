2 · Live database schema

Proposal — to build

Derived directly from the JSON contract: releases version each pipeline run, majors holds per-group headline fields (the baseline is just another row), and six child tables hold the chart data. All relationships are one-to-many.

releases 1 row / pipeline run
the unit of publication and audit
  • release_id PK
  • generated_date
  • snapshot_date
  • anchor_tiers
  • soc_sources · cip_sources
  • gate_results json
  • published bool

1 → many

majors
PK (release_id, major_key) · includes 'baseline' as a row
  • release_id PK FK
  • major_key PK
  • name · cip_families · nha_tier
  • records · persons · persons_anchored
  • anchor_drop_rate · persons_windowed_y10
  • unclassified_share · industry_unresolved_share
  • anchor_method_mix json · cip_source_mix json · soc_source_mix json
  • kpi_breadth · kpi_distinctive · kpi_up_share · kpi_dwell_median_mo

1 → many, each child keyed by (release_id, major_key)

fan_cells
destination-fan slices
  • release_id FK · major_key FK
  • soc_group
  • share · rr
  • n
Only cells with n ≥ 40 exist.
sectors
industry L1 shares
  • release_id FK · major_key FK
  • sector
  • share
  • n
curve_points
long-view curve
  • release_id FK · major_key FK
  • year
  • median_seniority nullable = suppressed
  • n
pillars
success-pillar scores
  • release_id FK · major_key FK
  • pillar growth | stability | skill | direction
  • score
Constructed framing; 50 = parity with baseline.
paths
counted pathway routes
  • path_id PK
  • release_id FK · major_key FK
  • n_persons
  • terminal_group
  • unexpected bool
  • grain 'soc_major_pooled'
path_stages
ordered stops of one route
  • path_id FK
  • position
  • soc_group
paths 1 → many path_stages.
Relationships (all 1-to-many)
  • releases → majors
  • majors → fan_cells
  • majors → sectors
  • majors → curve_points
  • majors → pillars
  • majors → paths
  • paths → path_stages
Release lifecycle: pipeline writes a release unpublished → gates + human sign-off flip published → portal reads the latest published release. Old releases are immutable and retained for audit.
